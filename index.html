Medical Multimodal AI AAAI 2027 투고 · 심사 중

ReSTAR

생성 X-ray를 학습에 쓰기 전에 신뢰성을 검증하는 방법

생성 흉부 X-ray가 읽을 수 있는 영상인지, 요청한 병변이 올바른 위치에 표현됐는지, 여러 모델이 같은 소견을 뒷받침하는지를 확인해 학습 후보를 선별했습니다.

  • 20,000생성 후보
  • 14,065선별된 학습 후보
  • 12 / 12평가 조합 AUPRC 개선
프로젝트 상세 보기

문제와 방법

희소 소견을 보완하려고 만든 합성 영상도 목표 병변이 보이지 않거나 위치가 어긋날 수 있습니다. ReSTAR는 영상 품질, 위치 근거, 모델 간 소견 근거를 독립적인 gate로 적용하고 확인하지 않은 소견은 음성 라벨로 단정하지 않습니다.

직접 맡은 일

연구 주제 선정과 문제 정의, 전체 연구 흐름 구성, 팀원 역할 분담을 맡았습니다. 방법론을 구체화하고 분류·검출 결과를 분석했으며 교수 피드백을 반영해 본문, 표, 그림, 실험 설정과 보충 설명을 정리했습니다.

결과와 한계

세 분류 backbone의 MIMIC-CXR·NIH 평가 12개 조합에서 평균 AUPRC가 모두 개선됐습니다. 다만 개선 폭은 조건별로 달랐고, 제한적인 전문가 평가는 합성 영상의 임상적 유효성을 확정하지 않습니다.

기술

PyTorch · CXR Classification · Detection · Vision-Language Model

02
Efficient AI · Autonomous Driving 게재 수락

자율주행 경로 예측 모델의 선택적 실행

예측 이력으로 Large model이 필요한 순간을 판단

Small model의 현재·과거 예측을 같은 미래 시각과 좌표계로 정렬해 비교하고, Large model의 추가 실행이 실제로 도움이 될지를 Router가 판단하도록 구성했습니다.

  • 1.67%Small 대비 ADE 감소
  • 12.8%Large 호출률
  • 3,486평가 프레임
프로젝트 상세 보기

문제와 방법

큰 모델이 항상 더 정확하지 않기 때문에 장면 복잡도만으로 호출 여부를 정하지 않았습니다. 같은 미래 시점을 가리키도록 예측 이력을 정렬한 ATSC 특징으로 Large model의 개선 가능성을 학습했습니다.

직접 맡은 일

공동 1저자로 참여해 데이터셋 관련 내용을 정리하고 최종 원고를 수정했습니다. 실험 조건과 결과가 과장 없이 전달되도록 평가 범위와 해석을 함께 점검했습니다.

결과와 한계

성공한 8개 주행에서 ADE가 3.012 m에서 2.962 m로 감소했습니다. 이는 저장된 주행 자료의 경로 예측 결과이며 실제 차량 제어, 충돌 회피, 폐루프 안전성을 검증한 결과는 아닙니다.

발표·기술

제7회 한국인공지능학술대회 게재 수락 · PyTorch · MetaDrive · MobileNetV4

프로젝트 상세 보기

문제와 방법

직접 맡은 일

LLM 연동과 챗봇 서비스 구조를 담당했습니다. 사용자 맥락을 반영하는 프롬프트를 구성하고 프론트엔드와 응답 데이터를 연결하는 방식을 팀과 조율했습니다.

확인된 범위

04
Medical Imaging · 2.5D MIL APCCAS 2026 Poster 수락

MRI 기반 PNI 예측

인접 단면과 축 방향 순서를 함께 사용하는 환자 단위 예측

간내담관암 환자의 수술 전 T2-weighted MRI에서 신경주위침윤(PNI) 위험도를 예측하는 연구에 참여했습니다. 인접 단면을 2.5D slab으로 묶고 순서 정보를 함께 집계합니다.

  • 183명단일기관 코호트
  • 0.770평균 AUROC
  • 5-fold환자 단위 평가
프로젝트 상세 보기

문제와 방법

PNI는 보통 수술 후 병리검사로 확인되지만, 수술 전 위험도 판단을 돕기 위해 환자 단위 라벨만 있는 약지도 학습 문제로 구성했습니다. OAS-MIL은 set-attention과 양방향 sequence-attention을 함께 사용합니다.

직접 맡은 일

서울대학교 의료영상 연구 인턴으로 연구 내용을 이해하고 논문 흐름과 결과 해석을 검토했습니다. Figure와 본문 설명이 일치하도록 표현을 개선했습니다.

결과와 한계

OAS-MIL은 AUROC 0.770 ± 0.077을 기록했습니다. 작은 단일기관 코호트에서 얻은 결과이므로 scanner, 촬영 protocol, 기관이 달라졌을 때의 외부 검증이 필요합니다.

논문·기술

프로젝트 상세 보기

연구 질문

편집 결과의 실패가 언어 지시를 반영하는 과정에서 생기는지, 3D 표현을 압축·복원하는 단계에서 이미 생기는지를 구분하는 것이 핵심 질문입니다.

진행 방식

편집을 제외한 압축·복원 실험과 여러 방법의 성공·실패 사례를 같은 기준으로 비교하고, 부품 보존과 공간 관계 변화를 중심으로 오류를 정리하고 있습니다.

현재 상태

멀티모달 연구실에서 진행 중인 연구입니다. 최신 실험 결과가 공개 가능한 형태로 정리되기 전까지 해결 완료나 정량 성능 향상을 주장하지 않습니다.

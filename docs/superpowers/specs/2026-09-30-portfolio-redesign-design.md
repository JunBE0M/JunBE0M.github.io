# 이준범 AI 포트폴리오 전면 개편 설계

## 목표

중앙대학교 AI학과 4학년 이준범의 실제 연구·개발 경험을 바탕으로, 신입 AI Engineer 지원에 사용할 수 있는 한글 중심의 단일 페이지 포트폴리오를 만든다. 채용 담당자는 첫 화면에서 이름, 전공, 핵심 관심 분야, 대표 연구를 파악하고 각 프로젝트의 문제·방법·역할·결과·한계로 바로 이동할 수 있어야 한다.

첫 수정본은 로컬 미리보기와 검증 결과까지 제공한다. push, merge, GitHub Pages 배포는 하지 않는다.

## 구현 범위

- 기존 `index.html`, `styles.css`, `script.js` 정적 구조를 유지한다.
- 서버, 프레임워크, 빌드 과정, 비밀 API 키를 추가하지 않는다.
- 기존 가짜 프로젝트, 수상, 연락처, LinkedIn 링크와 network canvas를 제거한다.
- 사용자 제공 사진과 확인된 연구 자료만 사용한다.
- 확인되지 않은 수상, CV 링크, 3D 편집 성능, SpotU 사용자 지표는 공개 화면에 표시하지 않는다.

## 확인된 콘텐츠

### ReSTAR

- 정식 제목: `ReSTAR: Reliability-Gated Synthetic Candidate Selection for Targeted Augmentation in Radiographic Findings`
- 상태: AAAI 2027 투고, 심사 중
- 문제: 생성 흉부 X-ray를 학습에 추가하기 전에 영상 품질, 병변 위치 근거, 모델 간 소견 근거를 검증한다.
- 결과: 20,000개 후보 중 14,065개를 선별했다. 세 분류 모델의 12개 평가 조합에서 평균 AUPRC가 모두 개선됐다. 개선 폭은 조건에 따라 다르다.
- 역할: 주제 선정, 문제 정의, 연구 흐름 구성, 팀원 역할 분담, 방법론 구체화, 분류·검출 결과 분석, 논문·실험 설정 정리.
- 제한: 원고는 익명 심사 중이며 공개 배포 금지 문구가 있으므로 PDF와 figure를 사이트에 싣지 않는다.

### 자율주행 경로 예측

- 제목: `시간 정렬된 예측 이력을 이용한 자율주행 경로 예측 모델의 선택적 실행`
- 영문 제목: `Selective Execution of Autonomous Driving Trajectory Prediction Models Using Time-Aligned Prediction History`
- 상태: 제7회 한국인공지능학술대회 게재 수락
- 저자 역할: 이준범 공동 1저자, 데이터셋 관련 정리와 최종 원고 수정
- 결과: 성공한 8개 주행 3,486프레임에서 ATSC-Fixed가 Small 단독 대비 ADE를 1.67% 줄였고 Large 호출률은 12.8%였다. 저장된 주행 자료의 경로 예측 평가이며 차량 제어·충돌 회피를 검증한 결과는 아니다.

### MRI 기반 PNI 예측

- 제목: `Order-Aware 2.5D Multiple Instance Learning for Preoperative MRI-Based Perineural Invasion Risk Assessment in Intrahepatic Cholangiocarcinoma`
- 저자: Hyunsu Go, Youngung Han, Kyeonghun Kim, Jinyong Jun, Junbeom Lee 외
- 상태: arXiv preprint, APCCAS 2026 Poster 수락
- 결과: 단일기관 환자 183명의 T2-weighted MRI를 사용한 환자 단위 5-fold 평가에서 AUROC `0.770 ± 0.077`.
- 역할: 연구 흐름과 결과 해석 검토, figure와 본문 설명의 일치 여부 개선.
- 제한: 작은 단일기관 코호트이며 외부 검증이 필요하다.

### SpotU

- Flutter와 Dart로 구현한 운동관리 모바일 앱이다.
- 사용자 목표, 운동 경험, 체중관리 정보를 LLM 응답 흐름에 연결했다.
- 역할: LLM 연동, 챗봇 서비스 구조, 사용자 맥락을 반영한 프롬프트 구성, 프론트엔드 연동 방식 조율.
- 사용자 수, 서비스 운영 성과, 추천 정확도는 표시하지 않는다.

### 3D 편집 연구

- 텍스트 기반 3D 편집에서 부품 누락, 위치·방향 오류, 원본 형상 변형을 분석한다.
- AnchorFlow, EditP23 등의 결과와 압축·복원 단계를 비교한다.
- 진행 중인 연구로 표시하며 해결 완료나 성능 향상을 주장하지 않는다.

## 시각 설계

- 밝은 아이보리 배경, 짙은 남색 본문, 절제된 청록 포인트를 사용한다.
- 레퍼런스의 연구자 소개형 레이아웃, 넉넉한 본문 폭, 논문형 제목 위계, 낮은 장식 밀도를 참고한다.
- 한글 본문은 산세리프, 큰 제목은 한글을 지원하는 세리프를 사용하되 시스템 폰트 대체를 제공한다.
- 모든 항목을 동일한 카드로 만들지 않는다. 프로젝트는 큰 행 단위, 논문은 서지정보 중심, 경험은 타임라인형으로 구분한다.
- 프로필 사진은 원본 비율을 유지하고 `object-fit: cover`로 과도하게 자르지 않는다.
- figure 또는 앱 화면은 출처와 의미가 확인된 경우만 사용하고 클릭 확대를 제공한다.

## 동작과 접근성

- JavaScript 없이도 핵심 콘텐츠를 읽을 수 있도록 본문을 HTML에 직접 작성한다.
- JavaScript는 모바일 메뉴, 상세 영역 보조 동작, 이미지 확대, 현재 연도 표기에만 사용한다.
- 모든 버튼과 링크에 키보드 포커스가 보이게 한다.
- 모바일 메뉴에는 `aria-expanded`와 명확한 레이블을 제공한다.
- 이미지에는 구체적인 대체 텍스트를 제공한다.
- `prefers-reduced-motion`을 존중한다.
- 임시 `href="#"`와 자료가 없는 버튼은 만들지 않는다.
